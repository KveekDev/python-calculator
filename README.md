# Python Calculator

My first programming project, developed in July 2026. This is an advanced console-based calculator designed to be robust and user-friendly.

## Features
- Error Handling: Full protection against invalid inputs and math errors (like division by zero).
- Operations: Supports addition, subtraction, multiplication, division, exponentiation (power), and square roots.
- History: Keeps track of all your calculations during the session.
- User Interface: Clean console interface with color-coded alerts and a smooth exit animation.

## How to use
1. Make sure you have Python installed.
2. Clone this repository or download the calculator.py file.
3. Run the script: python calculator.py
